## `whoami`

Full stack engineer, eight years of it, currently co-founding **Lego Verse Module** and building AI-driven SaaS on AWS. I care about one line more than any other in a system design: **where the LLM is allowed to make a decision, and where it absolutely is not.**

Most of what I ship follows the same shape — a deterministic core that owns state, money and limits, wrapped in a probabilistic layer that proposes rather than executes. Then a test that asserts every declared limit is actually enforced.

Lately that thesis lives in a workshop of **eleven local-first AI systems** running on my own hardware: trading agents, tutors, comic pipelines, meeting overlays. No API bills, no telemetry, no phoning home.

## The Workshop

Eleven systems, one thesis: **the model proposes, the deterministic core disposes.**

<table>
<tr>
<td width="50%" valign="top">

### [Vyuha](https://github.com/sathwikbairaboina2/Vyuha) &nbsp;`व्यूह`
**Supervised-autonomy options trading**

Defined-risk spreads on NIFTY and BANKNIFTY inside a mandate the human sets and can veto at any moment. Not an autonomous bot with a dashboard bolted on — the system forms a plan, the human approves or edits it, the machine executes strictly within it.

Design opens with a nine-defect audit of RakshaQuant. Every declared limit now has a test asserting it is enforced.

`NestJS` `LangGraph.js` `Kite Connect` `DynamoDB`

### [marketplace](https://github.com/sathwikbairaboina2/marketplace)
**Multi-tenant commerce + schema agent**

Two services decoupled by an SQS FIFO queue. A deterministic engine enforces a per-tenant dynamic schema registry; a conversational LangGraph layer turns a chat into a validated schema-change proposal. The agent never writes to the registry — it emits proposals the engine adjudicates.

`37.9k lines · 489 files · 293 commits`

`NestJS ×2` `Next.js` `LangGraph.js` `LocalStack` `Playwright`

</td>

character.ai-style: create AI characters with a persona, chat over a token stream, publish, follow other creators. Rebuilt from an AWS-Lambda prototype into two NestJS monoliths with a local-first dev stack. Shipped as four vertical slices — each a complete flow, not a layer.

`34.1k lines · 399 files · 277 commits`

**Agentic NSE paper trading**

A LangGraph pipeline of Groq-backed agents classifies market regime, picks strategies, validates signals. A deterministic rules engine does final approval, sizing and limits. LLMs reason about regime; they never touch execution.

Third-party repo, studied and hardened to v2.1. Paper-only by default.

`25.1k lines · 112 commits`

`Python 3.11` `LangGraph` `Groq` `LangSmith` `uv`

### [PersonalAITutor](https://github.com/sathwikbairaboina2/PersonalAITutor)
**Mastery-tracking tutor + simulation harness**

Built around one claim: task completion is not learning. Progress is per-concept mastery that decays over time — planning, difficulty selection, review scheduling and feedback are all queries against that single model, replayable from the attempt log.

Measured by a synthetic-learner harness with Claude as judge.

`15.5k lines · 199 files · 89 commits`

`NestJS ×2` `LangGraph.js` `mathjs` `DynamoDB + S3`

**Local comic generation studio**

Topic in, finished comic page out, entirely on your own hardware. A local LLM writes the script; ComfyUI renders panels; dialogue is composited at export so lettering stays crisp and editable. Every generation step is schema-validated and retried.

`14.4k lines · 141 files · 110 commits`

`Python 3.12` `FastAPI` `ComfyUI / FLUX` `Ollama` `Pydantic v2`

`NestJS` `Next.js` `BullMQ` `MinIO / S3` `Anthropic API` `Zod`

### [Invisible](https://github.com/sathwikbairaboina2/Invisible) &nbsp;🌐
**Capture-excluded meeting overlay**

Listens to a live conversation, transcribes it, streams advice onto a transparent overlay excluded from screen capture. **~673 ms to first word.** Nothing leaves the host: audio never hits disk, transcript is memory-only capped at 40 turns, one keystroke clears everything.

Ships with an honest statement of its own legal and ethical limits.

`8.7k lines · 68 files · 74 commits`

`Electron 43` `React 19` `whisper.cpp` `Silero VAD` `Qdrant`

</td>

**Local-first life tracker with voice**

Projects, todos, habits and reflection, managed by a LangGraph agent over voice, plus AI daily and weekly summaries. Every action also has a manual path — the tracker stays fully usable with the entire AI stack down.

`8.1k lines · 111 files · 45 commits`

`NestJS` `Next.js` `faster-whisper` `kokoro TTS` `LocalStack`

</td>

### [AeoGeo](https://github.com/sathwikbairaboina2/AeoGeo)
**AI-search visibility scanner**

Measures how discoverable and citable a site is to AI search engines, tracks it over time, captures the leads who asked. Built on three claims: AI crawlers mostly don't execute JS, cited passages cluster at 134–167 words, and `sameAs` entity linking is the strongest structured-data signal.

`7.7k lines · 74 files · 29 commits`

`NestJS` `Turborepo + pnpm` `DynamoDB` `LangGraph.js`

### [instascraper](https://github.com/sathwikbairaboina2/instascraper)
**Serialized media fetcher**

Two containers, one fetch worker thread. That single thread is the only code that talks to Instagram, which makes request serialization *structural* rather than a convention. All vendor code confined to one directory — an upstream breakage has a one-directory blast radius.

`Next.js` `FastAPI` `Instaloader` `Docker`

</td>

### [_devkit](https://github.com/sathwikbairaboina2/_devkit)
**Workshop boot harness**

One command per project: cold boot, health verify, run the tests. Some stacks need 3–6 containers, a seed step and a signed JWT before the first real assertion — these scripts collapse that gap to a single call, plus a port-ownership map and a live status dashboard.

`9 projects · 2,875 tests · one summary table`

`PowerShell` `Docker Compose` `LocalStack`
